# vehicle-dashboard

Aplicación web interactiva desarrollada con Streamlit para visualizar datos de anuncios de venta de coches.

Funcionalidades:
- Histograma de la columna "odometer"
- Gráfico de dispersión entre "odometer" y "price"

La aplicación está desplegada en Render: [https://vehicle-dashboard-uz32.onrender.com]
